# Java II · Muzeu i sendeve

Faqe vetëm front end (HTML + CSS, pa JavaScript). Hape `index.html` në shfletues.

## Skedarët

- `index.html` — struktura: header, navigim me ankora, tri karta (`article`), footer
- `style.css` — stili; grid që përshtatet me gjerësinë e ekranit
- `celesi.svg`, `filxhani.svg`, `bileta.svg` — ilustrimet

## Shënime para kodimit

- **Hyrjet:** klikimi mbi lidhjet e navigimit; klikimi mbi "Historia e fshehur".
- **Daljet:** faqja rrëshqet te karta përkatëse dhe e shënon; teksti i historisë hapet/mbyllet.
- **Rast normal:** klikoj "Filxhani" → kalon te karta e filxhanit; hap historinë → shfaqet teksti.
- **Rast kufitar 1:** ekran i ngushtë (telefon) → kartat renditen njëra nën tjetrën, pa rrëshqitje horizontale.
- **Rast kufitar 2:** përdorim vetëm me tastierë (Tab, Enter, Space) → lidhja "Kalo te përmbajtja", navigimi dhe `summary` funksionojnë dhe kanë fokus të dukshëm.
