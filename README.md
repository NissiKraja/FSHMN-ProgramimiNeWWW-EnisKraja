# FSHMN-ProgramimiNeWWW-EnisKraja

This repository holds my coursework for **Programimi në WWW** (Web Programming), part of the BSc Computer Science program at the Faculty of Mathematical and Natural Sciences (FSHMN), University of Prishtina.

Each folder corresponds to one assignment or lab session. Solutions are added to their folder as the course progresses.

## About the Empty Folders

Git does not track empty directories, so each folder from **Java I** to **Java XV** contains a placeholder `.gitkeep` file. This keeps the full structure in the repository from the start, before any work has been added.

Once a folder receives its real files, the `.gitkeep` placeholder is no longer needed and can be deleted.
